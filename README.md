# ROMULAS Portfolio — Homepage V1

Zero-cost static starter focused on the homepage experience first.

## Included
- Desktop cursor spotlight reveal: professional Romulas -> Muay Thai Romulas
- Eased cursor movement and subtle grid parallax
- Mobile static fallback
- Minimal feature-first homepage
- Scroll reveal transitions
- Responsive layout
- No paid framework, plugin, hosting or service required

## Preview locally
You can double-click `index.html`, or for a proper local web server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

- GitHub Pages

- Netlify
